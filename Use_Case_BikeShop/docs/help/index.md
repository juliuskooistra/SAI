# BikeShop help

BikeShop is a small online shop for a bike shop that **rents bikes out** by the
hour or day and **sells bikes**. It is a teaching example of the BFH Business
School: the shop is fictional, nothing is really rented or sold, and nobody
pays anything.

## For customers

- [Getting started and signing in](getting-started.md): create an account, sign in, sign out.
- [Renting a bike](renting.md): opening hours, the 15-minute grid, how the price is calculated.
- [Buying a bike](buying.md): reserve a bike, the 7-day hold, paying in the shop.
- [Your account and API tokens](account.md): tokens, usage limits, API keys.

## For shop staff

- [Staff pages](staff.md): today's board, the inventory, the price list, orders, analytics and jobs.
